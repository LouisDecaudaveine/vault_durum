# Recipes Index

This folder works best when each recipe is a single note and the shopping list stays separate.

## Recommended structure

- Food/Recipes/ for individual recipe notes
- Food/Shopping List.md for your active grocery list
- Food/Meal Plan.md for the meals you want to cook this week
- Food/Recipes/Recipe Template.md as a reusable recipe starter

## Suggested workflow

1. Create a new recipe note from the recipe template.
2. Add tags such as #recipe, #meal-prep, or #quick.
3. Link the recipe to your weekly plan or shopping list when it is being used.
4. Update the shopping list from the ingredients in the recipe notes.

## What a good recipe note should include

- A clear title
- Ingredients
- Steps
- Servings and timing
- Storage or leftovers notes
- Optional tags for diet, difficulty, or meal type

## Tip

If you want to make meal planning faster later, you can build simple automation around these note types rather than trying to manage everything in one page.
