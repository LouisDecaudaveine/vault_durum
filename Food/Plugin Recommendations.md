# Plugin Recommendations for Recipes and Meal Prep

## Plugins you already have

- obsidian-git: Great for version control, backups, and syncing changes from your computer to GitHub.
- obsidian-style-settings: Useful for making your notes easier to scan and visually clearer.

## Best next plugins for this workflow

### 1. Dataview
Best for: filtering recipes by tag, diet, prep time, or meal type.

Why it helps:
- You can build a view of all recipes that are vegetarian, high-protein, or quick to cook.
- It is ideal for creating a dynamic recipe index without manually maintaining lists.

### 2. Templater
Best for: turning your recipe template into a fast, repeatable workflow.

Why it helps:
- You can create a new recipe note in one click.
- It makes it easier to standardise recipe structure.

### 3. QuickAdd
Best for: adding new recipe notes and shopping list entries quickly.

Why it helps:
- You can create a button or command that opens a new recipe note with the right template.
- It is helpful if you want to build a very fast meal-planning routine.

### 4. Tasks
Best for: turning the shopping list into a practical checklist.

Why it helps:
- You can manage tasks inside your recipes and shopping lists.
- It works well for recurring prep tasks such as "buy ingredients" or "batch cook".

### 5. Advanced Tables
Best for: keeping simple ingredient or meal comparison tables when you want to compare options.

Why it helps:
- Useful if you later want to compare recipes by cost, protein, or prep time.

## Good optional plugins

- Calendar or Periodic Notes: Useful for weekly meal planning.
- Kanban: Helpful if you prefer a visual board for meal prep tasks.
- Mind Map: Nice for brainstorming meal ideas, but not necessary at first.

## Recommended setup order

1. Start with Dataview and Templater.
2. Add QuickAdd once you have a repeatable recipe workflow.
3. Use Tasks for shopping list and prep task tracking.
4. Add Calendar or Kanban later if you want a more visual planning experience.

## Sync recommendation

For phone use, Obsidian Sync is the cleanest option if you want reliable syncing across devices. Obsidian Git is good if you are comfortable with GitHub and want version history.
